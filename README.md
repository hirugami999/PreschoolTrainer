# Preschool Trainer — математический тренажёр

Flutter-приложение на русском языке для детей 5–6 лет. Помогает тренировать счёт в пределах 10, сложение, вычитание и состав чисел. Интерфейс использует крупные кнопки, короткие инструкции и понятную обратную связь.

## Возможности

- Выбор математической темы.
- Прибавление и вычитание 1, отдельные упражнения на сложение и вычитание с шагом от 1 до 10.
- Смешанные задания «+1 и −1».
- Состав чисел от 3 до 10: обычные примеры и поиск пропущенного слагаемого.
- Выбор ответа нажатием на число, показ правильного ответа и автоматический переход к следующему заданию.
- Прогресс серии и итоговое количество правильных ответов.
- Адаптивные карточки, общий математический фон и прокрутка на небольших экранах.

Серии счёта содержат 20 заданий, серии состава числа — 10. В сохранённом старом экране выбора «+1» есть пункт «Переместительный закон» с пометкой «Скоро»; отдельное упражнение для него пока не реализовано.

## Требования

- Flutter SDK с Dart, совместимым с ограничением `^3.13.5` в `pubspec.yaml`.
- Git.
- Для Android: Android SDK, настроенная Android Studio и подключённое устройство либо эмулятор.
- Для iOS: macOS, Xcode и инструменты, указанные в `flutter doctor`.

В проект включены платформенные каталоги Android и iOS. Каталогов для Web и Windows сейчас нет; их генерация не требуется для запуска на Android.

## Запуск

```bash
git clone https://github.com/hirugami999/PreschoolTrainer.git
cd PreschoolTrainer
flutter doctor
flutter pub get
flutter devices
flutter run -d <device-id>
```

Замените `<device-id>` на идентификатор Android- или iOS-устройства из `flutter devices`. Также можно открыть папку проекта в Android Studio, выбрать устройство и запустить `lib/main.dart`.

## Структура

```text
lib/
  main.dart                         # Точка входа PreschoolApp
  screens/
    home_screen.dart                # Главный экран
    math_screen.dart                # Выбор тем
    count_to_ten/                   # Счёт, операции и упражнения
      number_composition/           # Состав чисел и режимы заданий
    result_screen.dart              # Результаты серии
  widgets/                          # Общий фон, стиль, карточки и ответы
assets/images/                      # Фон и изображения главного экрана
android/                            # Android-проект
ios/                                # iOS-проект
practice/                           # Небольшой учебный пример Dart
test/widget_test.dart               # Проверки интерфейса и навигации
pubspec.yaml                        # Настройки, зависимости и ресурсы
pubspec.lock                        # Зафиксированные версии зависимостей
UI_CHANGES.md                       # Отчёт о приведении интерфейса к общему стилю
main.py                             # Сохранённый исходный Python-прототип
```

`main.py` сохранён из начальной истории репозитория. Он не используется Flutter-приложением; для его отдельного запуска нужен Python с `customtkinter`.

## Проверки

```bash
dart format lib test practice
flutter analyze
flutter test
```

Виджет-тесты проверяют адаптивность экранов при разных размерах и масштабе текста, карточки без переполнений, навигацию, ответы и завершение серии. Они не заменяют ручную проверку на устройстве.

## Android-сборка

Для локальной проверки приложения:

```bash
flutter build apk --debug
```

Для публикации потребуется настроить собственную release-подпись: текущая конфигурация release использует debug-ключ. Ключи, пароли, `key.properties`, локальные настройки SDK и файлы `.env` нельзя добавлять в Git.

## Работа с Git

Перед сохранением проверяйте состав изменений:

```bash
git status
git diff
git add <путь-к-файлу-или-папке>
git diff --cached
git commit -m "Описание изменения"
git push origin main
```

На чистом рабочем дереве перед началом работы можно получить изменения командой `git pull --ff-only origin main`. Если push отклонён, сначала разберитесь с удалёнными изменениями; принудительная отправка не нужна.

Для отмены опубликованного последнего коммита с сохранением истории:

```bash
git revert HEAD
git push origin main
```

Команда создаёт новый отменяющий коммит. Если есть незакоммиченная работа, сначала сохраните её отдельным коммитом или через `git stash push -u`. Для просмотра старой версии без изменения `main` используйте `git switch --detach <commit-hash>`, а для возврата — `git switch main`.
